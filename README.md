# Notre 11 type OL

Jeu entre Thib et Val : chacun compose son 11 type de l'Olympique Lyonnais (joueurs passés par le club depuis 2000), avec remplaçants et entraîneur. Les compos se synchronisent en direct (Firebase, projet partagé avec « Mon héroïne », document `families/ONZE-OL-THBVAL`).

Ajouter un joueur : ligne `Nom|POSTE` dans la liste `RAW` de `index.html` (postes : GB DD DC DG MDC MC MOC AD AG BU).
